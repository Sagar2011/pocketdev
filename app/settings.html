Help · Mute, disable, or uninstall

Click the avatar’s × to dismiss current reminders without approving anything in Claude. New requests can alert again. Claude does not report every approval or interruption: use this after approving a long-running command or cancelling in Claude if the reminder continues.

Turn off the sound toggles above to mute individual sounds, or Animate to stop movement.

To stop PocketDev immediately, right-click the avatar and choose Quit PocketDev. A new Claude session starts it again. Uncheck Start automatically with Claude in the same menu to keep it paused. Use /pocketdev:help in Claude to resume while the avatar is closed.

Disable the installed Claude plugin from a terminal:

claude plugin disable pocketdev@pocketdev-local

Re-enable it later with:

claude plugin enable pocketdev@pocketdev-local

Uninstall a user installation with:

claude plugin uninstall pocketdev@pocketdev-local

For project or local installations, run uninstall from that project and add --scope project or --scope local. Start a new Claude Code session after changing plugin status. For a temporary --plugin-dir test, start Claude again without that flag.

Disabling or uninstalling the plugin prevents future automatic starts. Quit the existing avatar too. Downloaded versions are in the runtime subfolder of the data folder below; you may remove that subfolder after quitting. Saved avatars and preferences are kept separately.
